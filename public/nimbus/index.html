Developers

One POST. Cited JSON back.

Authenticate with a bearer key, send a document id and question, and receive an answer plus source spans. Streaming and webhooks are available on Growth and Scale.

SDKs for Python and Node mirror the REST surface — no new concepts to learn.

curl https://api.nimbus.ai/v1/ask \
  -H "Authorization: Bearer $NIMBUS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "document_id": "doc_8f3a",
    "question": "What is the renewal notice period?"
  }'
import requests

res = requests.post(
  "https://api.nimbus.ai/v1/ask",
  headers={"Authorization": f"Bearer {API_KEY}"},
  json={
    "document_id": "doc_8f3a",
    "question": "What is the renewal notice period?",
  },
)
print(res.json()["answer"])
const res = await fetch("https://api.nimbus.ai/v1/ask", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.NIMBUS_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    document_id: "doc_8f3a",
    question: "What is the renewal notice period?",
  }),
});
const { answer } = await res.json();
